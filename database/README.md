Movan - Banco de Dados

Banco de dados relacional desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) do projeto Movan.

Tecnologias:
- PostgreSQL
- Neon Database
- SQL

Como utilizar:
1.Tenha o PostgreSQL instalado.
2.Crie um banco de dados para a execução dos scripts.
3.Execute sql/01_schema.sql para criar a estrutura.
